# Izdevumu izsekotājs (CLI)

Vienkāršs Python komandrindas lietojums ikdienas izdevumu uzskaitei. Programma ļauj pievienot izdevumus, skatīt sarakstu, filtrēt pēc mēneša, dzēst ierakstus, redzēt kopsavilkumu un eksportēt CSV failu. Visi dati tiek saglabāti JSON failā starp sesijām.

## Uzstādīšana

1. Klonē repozitoriju:
   git clone https://github.com/ligacirulex/expense-tracker.git

2. Ieiet mapē:
   cd expense-tracker

3. Palaist programmu:
   python expense_tracker/app.py

Nepieciešams Python 3.10+.

## Funkcionalitāte

1) Pievienot izdevumu  
2) Parādīt izdevumus  
3) Filtrēt pēc mēneša  
4) Kopsavilkums pa kategorijām  
5) Dzēst izdevumu  
6) Eksportēt CSV  
7) Iziet  

## Datu saglabāšana
Dati tiek glabāti failā `expense_tracker/expenses.json`.
